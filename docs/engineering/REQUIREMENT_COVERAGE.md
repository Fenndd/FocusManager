# Requirement Coverage and Planning Gates

Updated by T026 on 2026-11-17. This is a navigation/check map, not a second specification or an
implementation-status ledger. Requirement text and platform status remain in docs/spec/.

Every actual requirement definition is listed once below. Task links identify implementation owners
or explicit decision/research/decomposition gates. Several later gates create bounded child tasks;
those features are not yet fully decomposed or implemented. Update this map and ROADMAP.md when
children are created. Read the linked task to distinguish production implementation from preparation.
Cancelled T004/T010 do not provide coverage. APP-003 is removed by decision I1, with remaining legacy
behavior corrected by T012; PROT-011 and iOS remain deferred.

Owner scheduling update (2026-11-18): Linux-specific work is on hold until explicit owner resumption;
the ownership links below preserve future coverage and do not authorize resuming it. See
[owner decisions](../spec/decisions.md) and [STATUS.md](../../STATUS.md).

[T054](../../tasks/T054-fix-windows-path-compatibility-after-review.md), application-level SQLite
verification to [T055](../../tasks/T055-verify-windows-sqlite-startup-and-restarts.md), and technical
clarification of the proposed service design to [T056](../../tasks/T056-clarify-proposed-service-design-after-review.md).
These supplement T001/T002/T027 and do not complete their original criteria or later feature gates.
