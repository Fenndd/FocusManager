# Режим учёбы (SM)

### SM-001 Включение и выключение
Пользователь может включить и выключить режим учёбы из UI.

Платформы: Windows — done · Android — planned

### SM-002 Сохранение состояния
Состояние режима сохраняется между перезапусками. Если режим был включён, после перезапуска
агента (или устройства) он снова включён и ограничения действуют.

Платформы: Windows — done · Android — planned

### SM-003 Уже открытое не блокируется
При включении режима фиксируется снимок сессии. Приложения, запущенные до включения, продолжают
работать. Блокируются только **новые** действия (запуск, открытие папки, переход на сайт).

Платформы: Windows — done · Android — planned
> ❓ Вопрос: на Android «уже запущенное приложение» почти не имеет смысла (приложения живут в фоне).
> Нужно решить, что считать снимком на Android (например, приложение на переднем плане в момент включения).

### SM-004 Выключение снимает ограничения
При выключении режима все ограничения снимаются (в т. ч. политики браузера), снимок сбрасывается.

Платформы: Windows — done · Android — planned

### SM-005 Изменение белых списков при включённом режиме
Белые списки можно менять при включённом режиме; изменения применяются без перезапуска режима.

Платформы: Windows — done · Android — planned
Примечание: на Windows новые правила для приложений и папок применяются к следующему событию;
политика сайтов переприменяется сразу при сохранении.

### SM-006 Готовность белых списков
UI показывает, заполнены ли все категории белых списков, и предупреждает, если какая-то пуста.

Платформы: Windows — done · Android — planned

### SM-007 Статус агента в UI
UI показывает, доступен ли агент, и текущее состояние режима. Если агент недоступен — состояние «неизвестно»
и есть возможность обновить статус.

Платформы: Windows — done · Android — n/a (UI и агент в одном приложении — см. AND-001)
