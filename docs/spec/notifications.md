# Уведомления (NTF)

### NTF-001 Уведомление о блокировке
При блокировке приложения или папки пользователь получает уведомление: что заблокировано и почему.

Платформы: Windows — partial · Android — planned
Примечание: на Windows реализовано уведомление через значок в трее (`TrayNotifier`), но в агенте
сейчас зарегистрирован `SilentNotifier` — уведомления фактически выключены.
> ❓ Вопрос: уведомления выключены намеренно (слишком навязчивые)? Нужна ли настройка?

### NTF-002 Подавление повторов
Повторная блокировка того же объекта в течение 2 секунд не порождает повторного уведомления/записи в лог.

Платформы: Windows — partial (только для папок) · Android — planned
