# Белый список сайтов (SITE)

### SITE-001 Блокировка неразрешённых сайтов
Во время режима учёбы открытие сайта, хост которого не соответствует белому списку, блокируется.

Платформы: Windows — partial (только Google Chrome, через политики) · Android — planned

### SITE-002 Формат шаблона хоста
Запись белого списка — шаблон хоста:
- `example.com` — точное совпадение хоста;
- `*.example.com` — сам домен и все поддомены;
- `*` — любой хост.

Сравнение без учёта регистра. Схема, путь и порт в шаблоне не учитываются.

Платформы: Windows — done · Android — planned
> ❓ Вопрос: в Chrome-политике `example.com` матчится и на поддомены (особенность формата URLAllowlist),
> а в `RuleEvaluator` — только точный хост. Нужно выбрать одну семантику и привести к ней обе реализации.

### SITE-003 Нормализация ввода
При добавлении шаблон очищается: обрезаются пробелы и `/`; ввод с пробелами внутри отклоняется;
дубликаты не добавляются.

Платформы: Windows — done · Android — planned

### SITE-004 Пустой список — без ограничений
Если белый список сайтов пуст, сайты не ограничиваются.

Платформы: Windows — done · Android — planned

### SITE-005 Поддерживаемые браузеры
Windows: только Google Chrome (политики `URLBlocklist`/`URLAllowlist` пользователя).
Другие браузеры не ограничиваются.

Платформы: Windows — partial · Android — planned
> ❓ Вопрос: нужно ли блокировать другие браузеры (Edge, Firefox) — политиками или через белый список приложений?
