# Белый список папок (FLD)

Область применима к платформам с файловым менеджером, которым управляет FocusManager
(сейчас — Проводник Windows). На Android — `n/a`, пока не решено иное.

### FLD-001 Блокировка открытия неразрешённой папки
Во время режима учёбы открытие папки, которой нет в белом списке, блокируется.

Платформы: Windows — done · Android — n/a

### FLD-002 Совпадение папки
Папка разрешена, если её путь совпадает с записью списка (без учёта регистра, без завершающего разделителя).

Платформы: Windows — done · Android — n/a

### FLD-003 Вложенные папки
У записи есть флаг «разрешить вложенные папки». Если он установлен — разрешены и все подпапки;
если нет — только сама папка.

Платформы: Windows — done · Android — n/a

### FLD-004 Корень системного диска всегда в списке
Корень системного диска (`C:\`, без вложенных папок) всегда присутствует в белом списке
и не может быть удалён.

Платформы: Windows — done · Android — n/a
> ❓ Вопрос: зачем разрешён сам `C:\`? Если это нужно, чтобы Проводнику было куда «вернуться», — зафиксировать это здесь.

### FLD-005 Действие при блокировке
При открытии запрещённой папки окно (вкладка) возвращается назад к ближайшей разрешённой папке;
если это невозможно — окно закрывается; если и это невозможно — окно перенаправляется в первую
папку из белого списка.

Платформы: Windows — done · Android — n/a

### FLD-006 Виртуальные папки не блокируются
Виртуальные расположения оболочки (например, «Этот компьютер», `shell:`-пути) не блокируются.

Платформы: Windows — done · Android — n/a

### FLD-007 Несколько вкладок
Правила применяются к каждой вкладке окна Проводника отдельно.

Платформы: Windows — done · Android — n/a
