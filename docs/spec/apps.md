# Белый список приложений (APP)

Идентификатор приложения зависит от платформы: на Windows — путь к `.exe`, на Android — имя пакета
(`com.example.app`). Общие правила сравнения — в `FocusManager.Core` (`RuleEvaluator`).

### APP-001 Блокировка неразрешённого запуска
Во время режима учёбы запуск приложения, которого нет в белом списке, блокируется.

Платформы: Windows — done · Android — planned

### APP-002 Совпадение по полному идентификатору
Приложение разрешено, если его идентификатор совпадает с записью белого списка
(Windows: полный путь, без учёта регистра, после нормализации пути).

Платформы: Windows — done · Android — planned

### APP-003 Совпадение по имени файла
Если полный путь не совпал, приложение разрешается при совпадении имени исполняемого файла
(без учёта регистра). Нужно для событий, где известно только имя процесса.

Платформы: Windows — done · Android — n/a
> ❓ Вопрос: это ослабляет защиту (любой `code.exe` из любой папки будет разрешён). Оставить?

### APP-004 Пустой белый список
Если белый список приложений пуст, во время режима блокируются все новые приложения
(кроме системных, см. APP-005).

Платформы: Windows — done · Android — planned
> ❓ Вопрос: для сайтов пустой список означает «не ограничивать» (SITE-004). Нужна ли единая семантика?

### APP-005 Системные приложения не блокируются
Системные процессы и компоненты ОС, а также сам FocusManager никогда не блокируются.
Конкретный список — платформенный (WIN-003, AND-*).

Платформы: Windows — done · Android — planned

### APP-006 Редактирование списка
В UI можно добавить приложение (выбором файла или вводом идентификатора) и удалить его.
Нельзя добавить несуществующее приложение и дубликат.

Платформы: Windows — done · Android — planned
Примечание: на Windows путь должен оканчиваться на `.exe` и файл должен существовать.
