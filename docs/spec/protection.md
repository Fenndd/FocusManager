# Защита от обхода (PROT)

Уровни защиты от снятия блокировки самим пользователем (решения F1–F6, I5).
Уровень и его параметры задаются в профиле заранее (PRF-003).

### PROT-001 Четыре уровня защиты
Для каждого профиля пользователь выбирает уровень защиты (решение F1):
1. **Обычный** — сессию можно завершить в любой момент.
2. **С трением** — перед завершением нужно выполнить задание (PROT-002).
3. **Пароль** — завершить можно только по коду (PROT-003).
4. **Строгий** — до конца сессии завершить нельзя, кроме аварийного выхода (PROT-004, PROT-005).

Платформы: Android — planned · Windows — planned · Linux — planned · iOS — deferred
Примечание: на iOS строгий уровень обходится через Настройки (PROT-009).

### PROT-002 Трение
Задание перед завершением сессии настраивается заранее: пауза N секунд и/или ввод заданной фразы.

Платформы: Android — planned · Windows — planned · Linux — planned · iOS — deferred
> ❓ Вопрос: нужны ли другие задания (решить пример, подождать с открытым экраном и т. п.)?

### PROT-003 Пароль
Сессия завершается только после ввода кода, который пользователь задал при настройке профиля.

Платформы: Android — planned · Windows — planned · Linux — planned · iOS — deferred
Примечание: вариант «код хранит партнёр» отложен (PROT-011).

### PROT-004 Строгий уровень
Пока активна сессия строгого уровня:
- сессию нельзя завершить досрочно (кроме PROT-005);
- нельзя изменить правила профиля и уровень защиты;
- нельзя удалить FocusManager (PROT-007);
- закрыты выбранные экраны системных настроек, через которые можно отключить защиту (PROT-008).

Платформы: Android — planned · Windows — planned · Linux — planned · iOS — deferred

### PROT-005 Аварийный выход
В строгом уровне есть **ограниченный** аварийный выход: не чаще N раз за период и с задержкой M минут.
Параметры настраиваются заранее (решение F2).

- По умолчанию аварийный выход **включён**.
- Его можно **отключить совсем** — это опция при выборе строгого уровня.

Платформы: Android — planned · Windows — planned · Linux — planned · iOS — deferred
Примечание: аварийный выход через партнёра отложен (PROT-011).
> ❓ Вопрос: значения N, периода и M по умолчанию (предложение: 1 раз в неделю, задержка 10 минут).

### PROT-006 Ослабление защиты
Понизить уровень защиты или изменить параметры защиты профиля, у которого идёт сессия, можно только
пройдя проверку текущего уровня (задание трения, код), а на строгом уровне — нельзя до конца сессии.

Платформы: Android — planned · Windows — planned · Linux — planned · iOS — deferred

### PROT-007 Защита от удаления
В строгом уровне FocusManager нельзя удалить до конца сессии. Включается только с явного согласия
пользователя (решение F3).

Платформы: Android — planned (права администратора устройства) · Windows — research (агент как служба, WIN-010) · Linux — research · iOS — deferred (`denyAppRemoval`, ненадёжно)

### PROT-008 Закрытие системных настроек
В строгом уровне можно закрывать отдельные экраны системных настроек, через которые отключается
защита. Закрываются только они, а не все Настройки. Опцию можно включить или отключить (решение F4).

По умолчанию на Android: настройки специальных возможностей, страница FocusManager в списке приложений,
настройки даты и времени.

Платформы: Android — planned · Windows — research (Диспетчер задач, службы) · Linux — research · iOS — n/a

### PROT-009 Предупреждение о возможном обходе
Если на платформе защиту можно отключить в обход приложения (на iOS — отзыв доступа к Экранному
времени в Настройках), пользователь заранее предупреждён об этом в интерфейсе (решение F5).

Платформы: Android — planned · Windows — planned · Linux — planned · iOS — deferred
Примечание: уведомление партнёра об обходе отложено (PROT-011).

### PROT-010 Время, которое нельзя перевести
Таймеры сессий и аварийного выхода считаются по времени, которое пользователь не может перевести:
смена системных часов не сокращает сессию (решение F6).

Платформы: Android — planned · Windows — planned · Linux — planned · iOS — deferred

### PROT-011 Партнёр по контролю
**Отложено владельцем (2026-11-16).** Партнёр (друг, родитель) хранит код разблокировки, может
разрешить аварийный выход и получает уведомление при обходе защиты. Способ связи с партнёром не решён —
от него зависит, нужен ли облачный сервер.

Платформы: Android — deferred · Windows — deferred · Linux — deferred · iOS — deferred
