# Платформа Android (AND) — черновик

Статус: **черновик**. Требования ниже — гипотезы о том, как функции будут реализованы на Android.
Перед реализацией их нужно проверить (задача `0008`) и зафиксировать решение в ADR.

## Предполагаемые механизмы

| Функция | Механизм Android | Ограничения |
|---------|------------------|-------------|
| Обнаружение запуска приложения | `AccessibilityService` (события `TYPE_WINDOW_STATE_CHANGED`) и/или `UsageStatsManager` | Accessibility требует ручного включения пользователем; строгие правила Google Play по использованию Accessibility API |
| Блокировка приложения | Показ блокирующего экрана поверх приложения / `performGlobalAction(GLOBAL_ACTION_HOME)` | «Убить» чужой процесс нельзя |
| Блокировка сайтов | Локальный `VpnService` с DNS-фильтрацией, либо чтение адресной строки браузера через Accessibility | VPN — один на устройство; Accessibility зависит от конкретного браузера |
| Работа в фоне | Foreground service с постоянным уведомлением | Ограничения фоновой работы, энергосбережение производителей |
| Защита от выключения | Device Admin / Device Owner (опционально) | Device Owner требует специальной настройки устройства |
| Хранилище | Открыт: через серверный API к общему PostgreSQL или локальное хранилище на устройстве (ADR-0004) | Прямое подключение к PostgreSQL с телефона не рекомендуется |

## Требования

### AND-001 Единое приложение
UI и агент — одно приложение: агент реализован как foreground service, IPC между процессами не нужен.

Платформы: Android — planned

### AND-002 Идентификатор приложения
Приложение в белом списке идентифицируется именем пакета. Выбор — из списка установленных приложений.

Платформы: Android — planned

### AND-003 Системные приложения
Не блокируются: сам FocusManager, лаунчер, системный UI, экран звонка, настройки специальных
возможностей (чтобы пользователь не «заперся»).

Платформы: Android — planned
> ❓ Вопрос: разрешать ли «Настройки» целиком? Через них можно отключить сервис специальных возможностей.

### AND-004 Разрешения
При первом запуске приложение проводит пользователя через выдачу необходимых разрешений
(Accessibility, уведомления, VPN при необходимости) и показывает, каких не хватает.

Платформы: Android — planned
