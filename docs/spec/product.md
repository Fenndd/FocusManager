# Продукт

## Цель

FocusManager помогает сосредоточиться на учёбе: пользователь заранее составляет белые списки
(приложения, папки, сайты) и включает **режим учёбы**. Пока режим включён, всё, что не разрешено,
блокируется. Уже открытое до включения режима не трогается.

Целевая аудитория: пользователь, который ограничивает сам себя (самоконтроль), а не администратор,
ограничивающий другого человека.

> ❓ Вопрос: нужна ли защита от выключения режима самим пользователем (PIN, таймер, расписание)?
> Раньше это было в списке «не реализовано» (PIN protection and schedules).

## Глоссарий

| Термин | Значение |
|--------|----------|
| Режим учёбы (study mode) | Состояние, в котором действуют ограничения. Вкл/выкл пользователем. |
| Белый список (whitelist) | Набор разрешённых приложений / папок / сайтов. Всё, что не в списке, блокируется. |
| Снимок сессии (snapshot) | Список процессов/приложений, запущенных в момент включения режима. Они не блокируются. |
| Блокировка | Действие платформы, не дающее открыть запрещённое (завершение процесса, возврат из папки, политика браузера). |
| Агент | Фоновый компонент, который следит за событиями и применяет блокировки. |
| UI | Интерфейс для включения режима и редактирования белых списков. |
