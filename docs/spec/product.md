# Продукт (GEN)

Рабочее название: **FocusManager** (решение A4).

## Цель

FocusManager помогает сосредоточиться — прежде всего на учёбе. Пользователь настраивает **профили**
(«Учёба», «Сон», «Работа»…) с правилами, что разрешено или запрещено, и способами запуска
(вручную, по расписанию, по лимитам). Пока профиль активен, всё лишнее блокируется
на всех устройствах пользователя.

Это инструмент **самоконтроля**: пользователь ограничивает сам себя (не родительский контроль).

## Аудитория (решение A1)

1. Студенты и школьники — основной фокус продукта и маркетинга.
2. Все, кто хочет сосредоточиться: работа, сон, отказ от «залипания».

## Концепция (решение A2)

Два режима правил:
- **Белый список** (главный, отличие от конкурентов): во время сессии разрешено только выбранное.
- **Чёрный список** (привычный пользователям блокировщиков): блокируется выбранное.

## Направления развития (решение A3)

Все направления должны появиться в продукте; порядок задаёт дорожная карта.

| Направление | Кратко |
|-------------|--------|
| Учебные сессии | Предметы, наборы правил под предмет, режим экзаменов |
| Партнёр по контролю | Код разблокировки у друга/родителя, уведомление партнёру при обходе |
| Одна сессия на всех устройствах | Запуск на телефоне блокирует и ПК, и наоборот (требует облака) |
| Уровни защиты | Разная сложность снятия блокировки (детали — решения F, ещё не приняты) |
| Мягкое трение | Пауза, вопрос «зачем открываешь?» вместо жёсткого запрета |
| Игровая механика | Серии дней, достижения |

## Глоссарий

| Термин | Значение |
|--------|----------|
| Профиль | Набор правил (режим, списки, способы запуска, уровень защиты). См. `profiles.md`. |
| Режим белого списка | Разрешено только то, что в списках профиля (+ базовые необходимые приложения). |
| Режим чёрного списка | Блокируется только то, что в списках профиля. |
| Сессия | Период, когда правила профиля действуют. Начинается вручную или по триггеру. |
| Триггер | Способ запуска сессии: вручную, расписание, лимит, место/Wi-Fi. См. `triggers.md`. |
| Снимок сессии | Что было запущено в момент начала сессии (на ПК — не блокируется). |
| Блокировка | Действие платформы, не дающее открыть запрещённое. |
| Агент | Фоновый компонент, который следит за событиями и применяет блокировки. |
| Основные платформы | Android, Windows, Linux. |

## Общие требования

### GEN-001 Платформы
Основные платформы — Android, Windows, Linux; функционал на них одинаковый, на ПК дополнительно —
блокировка папок (решения B1, B5). iOS — после финализации основных платформ, только реализуемое
подмножество. macOS не планируется (решение B3).

Платформы: Android — planned · Windows — partial · Linux — planned · iOS — deferred

### GEN-002 Языки интерфейса
На старте — английский и русский. Все строки интерфейса локализуемы с первого дня (никакого
текста в коде), чтобы позже добавить все популярные языки (решение A5).

Платформы: Android — planned · Windows — planned (сейчас строки зашиты в код, только английский) · Linux — planned · iOS — deferred

### GEN-003 Регионы
Приложение распространяется во всех странах, кроме Китая (решение A6).

Платформы: Android — planned · Windows — planned · Linux — planned · iOS — deferred

### GEN-004 Поддерживаемые версии ОС
Поддерживаются версии ОС, покрывающие большинство используемых сейчас устройств (решение B6).
Конкретные минимальные версии — в `platforms/*.md`.

Платформы: Android — planned · Windows — done · Linux — research · iOS — deferred

### GEN-005 Работа без интернета
Все функции блокировки работают без интернета и без аккаунта. Облако нужно только для синхронизации
(см. `sync.md`, решение D1).

Платформы: Android — planned · Windows — partial (сейчас нужен сервер PostgreSQL — см. WIN-006) · Linux — planned · iOS — deferred
