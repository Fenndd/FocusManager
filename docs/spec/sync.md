# Аккаунт и синхронизация (SYNC)

Облачная платформа — Firebase (решение D2). В первой версии облака нет (решение D1).

### SYNC-001 Локально в первую очередь
Все данные хранятся на устройстве; приложение полностью работает без аккаунта и без интернета (GEN-005).

Платформы: Android — planned · Windows — partial (сейчас нужен сервер PostgreSQL — WIN-006) · Linux — planned · iOS — deferred

### SYNC-002 Аккаунт необязателен
Аккаунт нужен только для синхронизации. Без аккаунта доступны все бесплатные функции.

Платформы: Android — planned · Windows — planned · Linux — planned · iOS — deferred
> ❓ Вопрос: способы входа (Google, Apple, e-mail)? Связан ли аккаунт с покупкой премиума
> на разных платформах (решение G4)?

### SYNC-003 Синхронизация бесплатна
Синхронизация профилей, настроек и статистики между устройствами пользователя входит в бесплатный
базовый функционал (решение D3).

Платформы: Android — planned · Windows — planned · Linux — planned · iOS — deferred
Примечание: при большом числе бесплатных пользователей Firebase выйдет за бесплатные лимиты —
стоимость нужно оценить до запуска синхронизации.

### SYNC-004 Одна сессия на всех устройствах
Сессия, начатая на одном устройстве, действует и на других устройствах пользователя
(направление «Одна сессия на всех устройствах», `product.md`).

Платформы: Android — planned · Windows — planned · Linux — planned · iOS — deferred
> ❓ Вопрос: бесплатно или премиум (решение G2)?

### SYNC-005 Платформенные данные
Списки приложений и папок специфичны для платформы и синхронизируются только между устройствами
одной платформы; сайты, ключевые слова, расписания — между всеми.

Платформы: Android — planned · Windows — planned · Linux — planned · iOS — deferred
Примечание: на iOS приложения — непрозрачные токены, их нельзя синхронизировать даже между iPhone.
