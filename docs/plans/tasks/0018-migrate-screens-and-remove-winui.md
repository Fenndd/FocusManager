## Контекст

После каркаса (0017) нужно перенести экраны WinUI (`src/Windows/FocusManager.App/Views/`):
приложения, папки (с флагом вложенных папок), сайты, предупреждение о пустых категориях — и удалить
WinUI-проект. Задача 0004 (вынос проверки ввода из WinUI) отменена в пользу этой.

## Что сделать

1. Экраны списков приложений, папок, сайтов в Tauri: добавление (выбор файла/папки, ввод шаблона), удаление,
   флаг «включая вложенные папки».
2. Проверка и нормализация ввода (SITE-003, APP-006) — по правилам спецификации; где правило есть
   в общих тестовых примерах (`test-vectors/`, задача 0022) — тесты интерфейса используют их.
3. Предупреждение о пустых категориях по новой семантике (SM-006, PRF-004).
4. Удалить `src/Windows/FocusManager.App` из репозитория, `FocusManager.sln`, `FocusManager.Windows.slnf`;
   обновить скрипты запуска, `README.md`, `AGENTS.md`, `docs/spec/platforms/windows.md`.

## Критерии приёмки

- [ ] Все сценарии старого интерфейса работают в Tauri (ручная проверка на Windows).
- [ ] WinUI-проекта нет; сборка Windows не требует WindowsAppSDK.
