## Контекст

NTF-001 (решение E8): уведомления о блокировке включены по умолчанию и отключаются в настройках.
Сейчас в агенте зарегистрирован `SilentNotifier` — уведомления выключены, настройки нет. Трей и интерфейс
переезжают в Tauri (задачи 0016, 0017), поэтому уведомления показывает интерфейс, а агент сообщает
о блокировках событием по IPC.

## Что сделать

1. Событие «заблокировано» от агента к интерфейсу (контракт в `contracts/`).
2. Интерфейс показывает системное уведомление; настройка «Уведомления о блокировке» (вкл. по умолчанию)
   хранится локально.
3. Подавление повторов (NTF-002) — для приложений и сайтов тоже, не только для папок.

## Критерии приёмки

- [ ] Уведомление появляется при блокировке приложения и папки; выключается настройкой.
- [ ] NTF-001 и NTF-002 для Windows — `done`.
