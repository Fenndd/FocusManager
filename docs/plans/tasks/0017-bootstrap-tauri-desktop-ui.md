## Контекст

ADR-0007 (решение C3): интерфейс ПК — Tauri 2 + TypeScript + React, один для Windows и Linux.
Он заменит `src/Windows/FocusManager.App` (WinUI 3) и значок в трее агента.

## Что сделать

1. Проект в `src/Desktop/` (Tauri 2, Vite, React, TypeScript) с README: установка зависимостей,
   запуск в режиме разработки, сборка, тесты.
2. Значок в трее с меню: открыть окно, начать/завершить сессию, выход.
3. Связь с агентом: named pipe на Windows (Unix socket на Linux — заложить интерфейс), типы сообщений —
   сгенерированные из `contracts/` (задача 0005).
4. Главный экран: статус агента (SM-007), состояние сессии, кнопка начала/завершения (SM-001).
5. Локализация с первого дня (GEN-002): все строки в файлах переводов, английский и русский.
6. Сборка на Windows и Linux; проверить отображение в WebKitGTK на Linux (главный риск ADR-0007) и
   записать результат.
7. Job сборки интерфейса в CI (если задача 0006 выполнена). Обновить `AGENTS.md`.

## Критерии приёмки

- [ ] Приложение собирается и запускается на Windows и Linux; на Windows управляет сессией через агента.
- [ ] Строк интерфейса в коде нет — только файлы переводов (en, ru).
- [ ] Результат проверки WebKitGTK записан в «Результате»; при серьёзных проблемах — вопрос владельцу
      о переходе на Electron.

## Вне рамок
