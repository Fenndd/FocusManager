## Контекст

Сейчас сайты ограничиваются только в Google Chrome (`src/Windows/FocusManager.Platform.Windows/ChromePolicyRegistry.cs`,
раздел `HKCU\Software\Policies\Google\Chrome`). По спецификации (SITE-005, решение I4) поддерживаются
самые используемые браузеры: браузеры на Chromium читают те же политики, каждый из своего раздела реестра;
Firefox — своя политика `WebsiteFilter`. Остальные браузеры во время сессии блокируются целиком (SITE-006).

## Что сделать

1. Внутренний список поддерживаемых браузеров с расположением политик: Chrome, Edge, Brave, Vivaldi,
   Chromium (уточнить разделы реестра каждого) и Firefox (`Software\Policies\Mozilla\Firefox`, `WebsiteFilter`).
   Список — данные, а не код, чтобы его было легко дополнять.
2. Применение и очистка политик для всех установленных поддерживаемых браузеров.
3. Список исполняемых файлов известных браузеров; если профиль ограничивает сайты, неподдерживаемые
   браузеры блокируются как приложения (в т. ч. Opera, пока нет задачи 0011).
4. Тесты на тестовом разделе реестра (как `ChromePolicyRegistryTests`).

## Критерии приёмки

- [ ] Сайты ограничиваются в Chrome, Edge, Firefox, Brave (ручная проверка на Windows).
- [ ] Неподдерживаемый браузер не запускается во время сессии, ограничивающей сайты.
- [ ] Статус Windows в SITE-005/SITE-006 и WIN-005 обновлён.

## Вне рамок

- `HKLM` для строгого уровня — вместе с уровнями защиты (этап M5).
- Opera — задача 0011.
