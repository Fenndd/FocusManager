## Контекст

Облако — Firebase (решение D2, ADR-0006): аккаунт, синхронизация, аналитика, отчёты о сбоях.
**Нужны действия владельца:** создать проект Firebase в своём аккаунте Google и выдать доступ.

## Что сделать

1. Владелец создаёт проект Firebase (тариф Spark), регистрирует приложения: Android и веб (для Tauri).
2. Включить Authentication (e-mail и Google; для ПК — вход через системный браузер, ADR-0007),
   Firestore, Analytics, Crashlytics (Android).
3. Правила безопасности Firestore: пользователь читает и пишет только свои документы; тесты правил
   в эмуляторе Firebase.
4. Где хранится конфигурация приложений (что можно коммитить, что нет) — описать в `AGENTS.md`.
5. Оценить расходы при росте числа бесплатных пользователей с синхронизацией (SYNC-003).

## Критерии приёмки
