## Контекст

Решения G1–G6: подписки 1/3/6/12 месяцев, пробный период 7 дней с автопродлением, без покупки навсегда
и без рекламы; одна подписка действует на всех платформах; платная часть — с первого публичного релиза;
юридическая форма — решается до первого платного релиза. Android — Google Play; ПК — свой сайт и
Microsoft Store (решение H2).

## Что сделать

1. Google Play Billing: подписки, пробный период, отмена, возвраты; требования к экрану оплаты.
2. ПК: платёжный сервис для своего сайта (например, Paddle, Lemon Squeezy, Stripe — с учётом НДС ЕС)
   и покупки в Microsoft Store.
3. Учёт подписки на всех платформах: RevenueCat или собственный учёт в Firebase; привязка к аккаунту.
4. Что нужно юридически для продаж из Словакии (живность/компания, статус продавца по DSA в магазинах) —
   список вопросов для владельца и бухгалтера.
