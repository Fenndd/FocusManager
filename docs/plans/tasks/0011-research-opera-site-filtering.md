## Контекст

Opera — один из самых используемых браузеров (около 3% на ПК, около 2% на мобильных, StatCounter,
октябрь 2026) и должна поддерживаться (решение владельца 2026-11-16, SITE-005). Opera построена на
Chromium, но, по сообщениям пользователей и администраторов, **не читает корпоративные политики**
(`URLBlocklist`/`URLAllowlist`), которыми FocusManager фильтрует остальные браузеры на ПК.
Пока способа нет, Opera блокируется как неподдерживаемая (SITE-006).

## Что сделать

1. Проверить на Windows и Linux, действительно ли Opera и Opera GX игнорируют политики Chromium
   (реестр/JSON), в том числе в актуальных версиях.
2. Сравнить альтернативы для ПК, например:
   - расширение браузера (установка, защита от удаления, правила магазина расширений Opera);
   - фильтрация на уровне системы (локальный DNS/прокси, WFP на Windows) — только для Opera или для всех;
   - чтение адреса через средства специальных возможностей ОС (UI Automation на Windows, AT-SPI на Linux).
3. Проверить Android: работает ли с Opera способ через специальные возможности (адресная строка)
   и через VPN (задача 0008 смотрит общий случай).
4. Оценить надёжность, обходы, нагрузку, требования к правам.
